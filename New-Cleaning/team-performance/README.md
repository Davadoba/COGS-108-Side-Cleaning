# NBA Team Performance Cleaning

This folder contains the data cleaning and feature engineering
notebook for NBA team performance from the 2014-2015
through 2024-2025 seasons.

The dataset includes:
- Approximate regular-season conference rankings
- Playoff qualification
- Furthest playoff round reached
- Five-year playoff appearance history
- Five-year average playoff round

The cleaned data will be used alongside player statistics
and salary information to predict NBA player trades.
